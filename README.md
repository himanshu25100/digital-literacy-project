### Module Summaries:
##### Module-1:Hands on Training on Presentation Softwares and Spreadsheet
Module 1 focuses on presentations softwares such as Microsoft powerpoint, canva, prezi and spreadsheets softwares such as google sheets, excel, using functions and formulas, it teaches on how to present data in a eye-catching way so that it is communicated properly 
##### Module-2:Programming Platforms & Collaborative Learning Platforms
Module 2 talks about the use of programming platforms and how they can be used to help ourselves prepare for challenges and interviews that we might face in the future some examples are Leetcode, Hackerrank, Kaggle, etc.
It also goes into detail about how collabrative learning platforms such as Google Worskspace and Notion can be used to benefit of the students and help them organise and making their learning journey easier.
##### Module-3:Building a Digital Portfolio
Module 3 dives into how important it is to build a professional digital profile and how useful it can be present ourselves to potential employers, some of these platforms incluse LinkdeIn: which can be used to build an online presence share our experiences and what we have learned form that, Github: where we can Share our projects and work on open sources contributing to the society. Stack Overflow, Which serves as a community for developers helping each other,etc
##### Module-4:Email Etiquette & basics of social media etiquette
Module 4's all about professional communication skills, most important of them being how to write a proper professional email, accurately communicating what we mean, how to greet, giving a proper subject line, and also how to end off the email with relevant details, also tesaches how to reply to a mail, useful tips to attach files, etc.
##### Module-5:Awareness on Cyber Crime and Financial Fraudulent
As the name suggest this module is about Cybercrime, It provies a description of Cyber crimes and types, crimes in Financialdomain with Use case, crimes on Personal level, Cyber crime Flowchart, Prevention measures, Social Media Etiquette, Digital Hygiene, Online certification platforms.
How to be more careful while browsing the internet not to click on suspicious links and making sure before a payment.
